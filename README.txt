Series OST Tracker Template-Automated

Tool 中为 Template 工具，Example 中含泰剧《偿还 Payback the Series》的“扒 OST 列表”本表。

一个通过 VBA 脚本和个别 Excel 菜单工具实现自动化的 Excel 表格 template 工具，有 sheet1 和 sheet2 交互处理数据，sheet1 作为负责“登记造册”的登记表，sheet2 作为负责“录入与统计”的条目库。

使得扒全剧为10集的影视的全部 OSTs 更省力，减少手动输入、查找、复制粘贴和错误检查等工作。

这个工具有非常强的“量身打造”属性，除了作为 OTS 追踪列表，以后在不做任何适配改动的前提下，只适用于全10集的影视剧，并且按照表头严格要求数据具有 Episode、Timestamp、Title、Artist、Album、Note等信息，详见表工具。

若要处理不同的数据，则需要对代码进行相应调整。

主要功能表1：
- 手动登记出场的曲的信息。
- 对于非首次出场的曲，之后每一次出场的登记都可以通过 Title 栏下拉菜单选中对应 Title，后面的其它信息会自动填充。
- 登记或改动曲目信息会反馈到表2，以便表2实时调整收录信息

主要功能表2：
- 从表1去重收录曲目
- 记录没有 Title 的曲片段的数量，也就是全剧未能识别出曲目的曲片段出场场数，不代表这些曲片段一定不来自已收录曲目或互相之间不重复。主要反映了全剧有多少曲片段是无论如何听歌识曲识别不出来的。
- 删除收录曲目并反馈变更到表1，比如在多条同名不同 TAAN pattern 的曲目中删一条曲目则可选择某一同名条目为目标条目，将表1相应的原条目登记信息换为目标条目的信息，若某名条目只有一条收录则无法被删除。（TAAN 代表 Title、Artist、Album、Note，表2收录曲目的标准是 TAAN 唯一，比如表1中有两条曲A的登记信息，一条是 TAAN1，另一条 TAAN2，说明这两个曲片段可能来自同一个曲目的不同版本，它们拥有相同的 Title、Artist、Album 但 Note 中注释了它们各自的不同的版本信息，那么这两条登记的曲就会被视为 TAAN pattern 不一样并当作独立的两条曲目收录到表2，若改二者之一的备注到与另一方相同，则只剩另一方的收录，二者被视为 TAAN 相同的同一曲目）。
- 修改收录曲目 TAAN 中的任一信息，则表1中相应的登记信息全部更新，比如出场场次 EP1 3:25、EP1 16:07、EP2 45:19的曲为同一首曲B，在表2中改其名为曲Bb，则表1中这三个场次登记的曲信息的 Title 会从曲B变为曲Bb，AAN 信息同理。
- 记录收录曲目的首出场时间，从表1获取该曲目的首条登记中的 Episode 和 Timestamp 信息，记录到表2的 First Appears。
- 统计每条曲目在全剧以及分别每一集的出场次数。

取消了10集限制，表2的单集曲目出场次数数据列将根据在表1 A列中检测到的 EP 数来自动延伸，比如表1中当前登记到 EP3 ，则表2 I列 First Appears 右侧起延伸出 EP1、EP2、EP3 三列，之后登记到 EP5 就延伸到 EP5。

如果 EP1、EP2、EP3 后 直接写 EP6，也会当作连续集数延伸出完整的EP1、EP2、EP3、EP4、EP5、EP6，不过其中 EP4、EP5 列会空着。

新增宏按钮”btnEPstats“，使”曲单集出场次数数据是否显示“可选。按钮名称显示是”Hide EP stats“和”Show EP stats“，分别对应”当前单集数据已展开“和”当前单集数据已隐藏“状态以及功能”隐藏单集数据“和”展开单集数据“，初始化时调用展开 EP stats 函数，所以按钮默认的显示名称是 Hide EP stats。只有一次初始化，此后操作会被记住和同步，hide之后，无论是切换表单还是关闭再打开表，都不影响上一次操作后的状态，也就是单集数据是被隐藏了的，show同理。（02:49）
